## 新增功能

六页导航：价格排行榜 / 性价比 / 模型对比 / 性能排行榜 / 大模型科目三 / 开放数据。

1. **模型对比**：勾选 2–4 款，对比输入/输出/缓存/任务成本、三种场景单次成本、上下文、最大输出、阶梯档位、Batch/低峰、状态与最后核验；最优值高亮，条形按行内最大值归一。清单写进 URL。
2. **最近上架 / 最近调价**：首页顶部两张卡。调价卡比较相邻两条历史快照的所有档位，识别价格、档位上限、可用输入和档数四类变化；30 天无记录时回退半年窗口。
3. **性价比散点图**：Arena 分 × 价格，对数价格轴，标注帕累托前沿并附前沿表；文本/编程/视觉三张分开，不与智能体榜混分。
4. **详情页价格走势**：内联 SVG 折线（零依赖），单条记录时改画阶梯图。
5. **月账单估算**：按当前筛选与「每天 N 次 × M 天」算月成本，给出最省/最贵与倍数。
6. **迁移计算器**：详情页按月账单列出用途相交的更省/更贵同类模型及节省比例。
7. **CSV 与开放数据**：新增 `/data/models.csv`（22 列，含人民币换算与任务成本）与 `/api/` 文档页，说明五个端点的字段口径。
8. **收藏**：`localStorage` 保存，可「只看我的收藏」，收藏数显示在筛选栏。
9. **汇率可调**：首页汇率输入框贯穿全部报价与排序，重置回 `catalog.meta.usdToCny`。
10. **分享图**：Canvas 2x 导出 1080 宽 PNG，含标题、口径、前 8 名与并列名次。

## 工程

- 校验：`validate:data` → `astro check` → `astro build` 共 168 页；`validate:build` 通过 4,163 个本地链接/资源；`npm test` 228 项通过。
- `scripts/validate-build.ts` 的静态页常量改为 7，并新增对比/性价比/开放数据三页的导航断言与 CSV 行数断言。
- 新增 `npm run snap`：把 `dist` 展开成自包含 HTML 并用本机 Chrome 截整页 PNG，用于视觉回归；分享图借 esbuild 打包后真实渲染。
- 修掉的渲染缺陷：性价比页厂商 Logo 被 Astro 转义成源码、散点标签重叠、对比条形溢出、分享图副标题压住表头、移动端导航撑破 390px、迁移表在快照里用的手抄数据。

## 已知边界

- Arena 榜单自身更新滞后（当前快照已 60 天未更新），性价比页会显式提示，不用旧分假装新分。
- 自动抓取仍是 8 家；OpenAI、Anthropic、Google、xAI 依赖人工核对。
- 分享图为 Canvas 绘制，依赖系统字体，不同平台字形略有差异。
