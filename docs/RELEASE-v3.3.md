# v3.3 发布说明（2026-11-12）

产品基线见 [PRD v3.3](../PRD.md)。本版把 B 档的四件事做完，并补齐 A 档留下的样式缺口。

## 1. 退役倒计时

- 数据层：`modelSchema` 新增 `retireAt`，并有守卫只允许 `deprecated` / `retired` 的型号标注下线日期，避免给在售型号误写死期。
- 已标注 6 款：`minimax-m2-7`、`minimax-m2-7-highspeed`（2026-11-18），`claude-sonnet-4-5`（2026-11-30），`kimi-k2-7-code`、`kimi-k2-7-code-highspeed`、`kimi-k2-6`（2026-12-31）。
- 展示层：`src/lib/retirement.ts` 的 `countdown()` 只给三种语气 —— 七天内「N 天后下线」用警示色、当天「今天下线」、已过公告日期「已过公告下线日」。榜单行内（60 天内才出现）、详情页徽章与提示段、`/status/` 的下线时间表共用同一函数。
- 基准日一律取当天，不取数据核验日：否则页面会停在发布那一刻，倒计时永远不动。

## 2. 命令面板与快捷键

- `⌘K` / `Ctrl+K` 打开命令面板，`/` 优先聚焦页面搜索框，没有搜索框时开面板，`?` 列出全部快捷键。
- 面板**首次打开才** `fetch` `data/catalog.json`，不把 161 款打进每个页面的首屏。
- 榜单页：`j`/`k` 上下选中行（左侧蓝条 + 深蓝底），`Enter` 打开详情，`f` 收藏，`c` 加入对比。输入框内不劫持按键。
- 修掉的真实缺陷：处理器里原本写 `(event.target as HTMLElement)?.closest(...)`，当 `event.target` 是 `document` 时 `.closest` 不存在，抛错把整个处理器打断 —— 面板打不开、快捷键全失效。改成先判 `event.target instanceof Element`。

## 3. 对比结果分享图

- 对比页右上角新增「下载对比图」，与「复制对比链接」并列。
- 输出 1080 宽、2 倍图，列数为所选 2–4 款：输入、输出、缓存读取、单次任务成本、上下文窗口、阶梯档位、模型状态；最优项标绿，页脚印口径与站点地址（读 canonical，换域名不用改代码）。
- 与榜单图共用 `siteLabel()`、裁字与圆角工具，视觉一致。

## 4. 价格变化指数

- 结论先说：**目前是一条 100 的平线**。161 款里 16 款有两条以上历史记录，其中 14 款费率数组真有差异，但差异全在档位上限、档数、Batch 折扣或档位名称上，首档输入价一条都没变。
- 因此页面照实画平线、省掉刻度线（否则唯一刻度会被读成「跌到 98」）、写「两次观测都是 100，没有变化」，并把 3 款动档位结构的型号单列成表、说明另 11 款只动了 Batch 折扣。隐藏这张图才是错的。
- 口径：只纳入历史里出现过差异的型号，等权（没有调用量就不编权重），只在观测日取值不插值，各自首档标准输入价、原币种比较。
- 指数按 `JSON.stringify(rates)` 指纹判断有没有变化，不按单价筛 —— 按单价筛会把 14 款全漏掉。

## 5. 工程变化

- `/status/` 此前只有 class 没有 CSS，两套主题下都是裸文本；本次补齐 `.status-*` 一整块样式，含 900px / 680px 两档断点。
- 新增单测：`tests/retirement.test.ts`（3 例）、`tests/price-index.test.ts`（5 例）。`npm test` 242 pass / 0 fail。
- 截图工具支持 CDP `Emulation.setDeviceMetricsOverride`，真 390px 视口才能命中 `@media (max-width:480px)`（Chrome 窗口最小宽度是 500px，`--window-size=390` 只会裁图）。

## 7. 已知边界

- 价格变化指数样本只有 14 款，且当前无单价变动；它回答的是「这批有记录的型号变没变」，不是全站价格水平。
- Arena 成绩榜已 60 天未更新，页面照实标出日期与天数。
- OpenAI、Anthropic、Google、xAI 四家仍需人工核验，`/status/` 写明了这一点。
- 分享图由 Canvas 绘制，字体取决于本机是否装了中文无衬线字体，不同系统上字形会有差异。
- 命令面板结果按需拉取，首次打开有极短网络等待；离线时面板不可用，但页面其余部分不受影响。
